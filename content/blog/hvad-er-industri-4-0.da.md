---
title: "Hvad er Industri 4.0?"
---

Industri 4.0 er det stadie, industrien står i nu, hvor produktionen bliver mere og mere digital, forbundet og styret af data.

Det er den fjerde i rækken af industrielle revolutioner:

- den første var drevet af damp
- den anden af elektricitet og samlebånd
- den tredje af computere
- den fjerde af forbundne, digitale produktionssystemer

## De fire principper i Industri 4.0

Industri 4.0 bygger på fire principper:

1. **Forbundne systemer**  
Maskiner, enheder, sensorer og mennesker kan kommunikere med hinanden gennem forbundne systemer som IoT.

2. **Gennemsigtig information**  
Data gør de ændringer i produktionen synlige, som ingen kunne se før, så det bliver lettere at handle på dem.

3. **Teknisk assistance**  
Systemerne kan hjælpe med at træffe beslutninger og hjælpe mennesker med opgaver, der er svære eller farlige.

4. **Decentrale beslutninger**  
Maskiner og software kan løse visse opgaver selv ud fra data og regler.

## Teknologien bag skiftet

Det er en bred vifte af teknologier, der gør det muligt, for eksempel:

- mobile enheder
- IoT-platforme
- intelligente sensorer
- 3D-print
- big data og analyse
- maskinlæring og kunstig intelligens
- avanceret visualisering af data

Tilsammen gør de grænsen mellem menneskers arbejde og maskinernes beslutningsstøtte mere og mere flydende.

## Industri 4.0 i praksis

Industri 4.0 kan godt lyde som endnu et modeord. Men skiftet bag ordet er virkeligt.

Produktionssystemerne kan i stigende grad:

- kommunikere, uden at et menneske skal gøre noget
- analysere store mængder data
- reagere automatisk i udvalgte situationer

Spørgsmålet for producenterne er ikke, om forandringen sker. Det er, hvor hurtigt de følger med.

Så tænk over, hvad det næste skridt er på jeres egen digitale rejse.
